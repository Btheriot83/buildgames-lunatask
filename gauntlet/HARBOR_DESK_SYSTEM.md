# Harbor Desk design system (from assets)

Catalog: design-system-from-assets. Assets: `public/imagine/tideglass-mark.jpg`, `empty-tide-desk.jpg`, `public/motion/tide-desk-drift.mp4`, live blotter, Things 3 / Structured product shots.

## Read from the mark
Olive notebook on a tidewater desk. Sea-glass bottle. Brass cup. Bone. Flat daylight, no glow. The object is a desk, not a dashboard.

## Tokens (locked)
- Field: `#0b1c24` ink
- Paper: `#f4efe6` bone, grain OK, no gradient
- Ink on paper: `#0e1a20`
- Seafoam CTA: `#2f7f78`
- Coral now/habit: `#c45b4e`
- Brass mark edge: `#a8893e`
- Type: Fraunces **mark-only**. IBM Plex Sans UI. IBM Plex Mono time.

## Patterns
- Today is one editorial list (Things). Hour rail + Now (Structured).
- Groups: This tide / Later / This evening.
- Checks: square for tasks, ring for habits.
- Utilities (Export, Ledger) stay in the ink field, not on the blotter.

## Do
- Flat fills. Quiet headings. One job: Today.
- Living tide lines behind the desk — restrained, no cheese orbs.

## Don’t
- Soft gradients, glass, vibe-purple, Inter/Geist, Fraunces as page default.
- Meters, hero bands, AI chrome on the fold, 3-card triad, P-pills on Today.
