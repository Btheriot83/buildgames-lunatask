# Tideglass friend walkthrough

**Activation event:** First habit checked or first task added on Today.

## Cards (3)
1. Today is the desk — One blotter. Scroll for Tasks, Habits, Mood.
2. Check something off — Tap a habit on Today. That is enough.
3. Add one thing — Type under Today. Tasks holds the rest.

Skip always available. Persist `localStorage.tideglass-walk-done`. Sample data is already seeded so the desk is usable before the cards finish.
